# Example Plan — Worked 7-Day LinkedIn Plan

This is a filled-in plan the planner would emit for a real founder. Every pillar,
formula, CTA type, and goal below matches `../SKILL.md` exactly — the Formula →
pillar mapping, the CTA type vocabulary, and the Weekly inbound-readiness check
are the same tables, not a variant. Use this as the format reference for your
own runs.

## Inputs

- **Theme:** Ship AI products without raising
- **Audience:** Pre-seed B2B SaaS founders, ages 28-40, US/EU split
- **Persona:** Founder (general plan requested, not the founders-edition angle set)
- **Pillar mix:** 40% Authority, 30% Narrative, 20% Community, 10% Product
- **Posting days:** Tue-Fri (4 posts); Mon stays a comment-only day
- **Follower count:** 6,200 (5k-20k band: 10-20 comments/day)
- **Recovering account:** No
- **Voice profile:** not filled; voice samples supplied instead — 8 past posts, lowercase starts, `..` soft pauses, sentence fragments common
- **Timezone:** schedule for US East morning (EU mid-day overlap)

## Daily Comment Targets

Follower count is 6,200 (5k-20k band), so the default 10-20/day target applies without adjustment. Under 1,000 followers, weight this 2:1 toward commenting instead; above 20,000, the 10-20/day floor still holds but posting can carry more of the week.

### Mon (comment-only day, target 25-30)

- **5 peer founders** at 5-20k followers (warm reciprocity)
- **3 aspirational** at 50k+ (creators 2-3 tiers above you in same niche)
- **2 prospects** (founders posting AI-product-launch content)
- **Pattern:** answer-the-closing-question + data-first

### Tue, Wed, Thu, Fri (post days, target 15-20 each)

- **3 peer comments** (warm reciprocity inside 90 min of your post)
- **3 aspirational comments** (first-commenter slot if you can catch the post in <10 min)
- **2 prospect comments** (long-form, save-worthy substance)

## Weekly Inbound-Readiness Check

- [x] At least 1 vulnerability post (Wed, F4 Confession)
- [x] At least 1 receipt/data post (Tue, F7 Odd-Precision Money)
- [x] At least 1 soft offer or CTA-driving post (Tue's Specific question and Wed's Mirror question both drive a concrete reply)
- [x] Comment strategy includes 70% peers / 20% aspirational / 10% prospects
- [x] No pillar >60% of the week (Narrative is 50%, under the cap)
- [x] No duplicate formula used twice (F7, F4, F14, F11 all distinct)
- [x] Goal mix spread: Saves, Comments, Reposts, Likes each appear once — no reaction is chased twice

## Notes

- All timing recs sit inside the Tue/Wed/Thu prime window per `pillars-framework.md`. Fri is post-cutoff (after 2 PM is unsafe, but 9:00 AM is fine).
- Voice fingerprint: the user's lowercase-start preference is honored across all 4 hooks (no filled Voice Profile yet, so this came from the pasted voice samples). Proper names (people, brands) stay capitalized.
- CTA types are drawn from the closed vocabulary in `../SKILL.md` § Output: Specific question, Mirror question, Tag prompt, No CTA. Thu's Named Gratitude post uses Tag prompt rather than a question, because the ask is to name someone, not to answer something.
- Pillar mix sums to 100% (40 + 30 + 20 + 10); this is standard mode, not founders-edition, so the exact-100% check applies, not the founder mode's 85-115% range check.

## Variations

### 4x/week starter cadence

Drop the Friday slot. Tue/Wed/Thu/Mon-comment. Use this for the first month while voice/audience calibrate.

### 5x/week scaling cadence

Add the Mon Product slot above OR add a Fri-afternoon community spotlight (`F6 Comment-Gate` with a cohort tag, used sparingly and never with "comment X to get Y" phrasing — see its 2026 note in `../../../references/hook-formulas.md`). Only do this when post-1 average dwell-time exceeds 31s and comment volume is sustainable.

### Launch week

Replace Tue Authority with a `F2 R.I.P. Obituary` framing the old category as dead (Goal: Reposts, CTA: Soft offer). Replace Fri with a `F8 Paid-vs-Free Reversal` showing the alternative your product is (Goal: Saves or Reposts — F8 earns both in the canonical split, pick by which framing the angle actually leans on).

### Recovery mode

If the account had gone dormant or been shadowbanned before this week, none of the above applies: return the 5-step protocol from `pillars-framework.md` § Recovery / cold-start 5-step protocol instead (days 1-5 comment-only, week 2+ resumes posting). Re-plan a standard week like this one only after week 4 of that protocol.
